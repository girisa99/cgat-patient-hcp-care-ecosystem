# Memory: architecture/marketing/genie-cast-four-tab-consolidation-v5
Updated: just now

The Genie Cast CREATE quadrant is organized into a three-stage progressive workflow: **Templates** (blueprint selection), **Messaging** (AI copy generation only — no pipeline tracker or regional config), and **Production Setup** (unified Styles + Brand Assets + Regional Config). The AuthoringStageIndicator (8-stage pipeline) was removed from Messaging and now lives in: (1) the WorkflowContextBanner for CREATE-level progress, and (2) the Studio sub-tab in PRODUCE for detailed stage tracking. The Production Setup tab uses internal section navigation (Styles | Brand Assets | Regional Config) to consolidate what were previously separate 'Styles' and 'Assets' sub-tabs. Brand Assets auto-populates based on the product context from the session (selected template category or approved messaging productId). After messaging approval, the flow navigates to Production Setup; after setup, a 'Go to Produce' button bridges to the PRODUCE quadrant.
