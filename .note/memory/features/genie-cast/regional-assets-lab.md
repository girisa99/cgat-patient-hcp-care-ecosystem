# Memory: features/genie-cast/regional-assets-lab
Updated: just now

The 'Regional Assets Lab' in Genie Cast manages a 'Generate → Preview → Approve → Publish' workflow for 20 asset types: 3D Avatars, Hero Videos, Promo Clips, YouTube Intros, Hero Images, Thumbnails, Infographics, Typography Art, OG Images, Brand Logos, Banner Ads, Email Headers, Social Stories, LinkedIn Posts, LinkedIn Banners, YouTube Thumbnails, X/Twitter Posts, WhatsApp Status, Audio Intros, and Podcast Covers. It features 12 creative styles (Pixar 3D, Anime/Ghibli, Photorealistic, Crayon, Cyberpunk, Claymation, Comic, Watercolor, Pop Art, Isometric 3D, Stained Glass, Ukiyo-e) that apply universally to ALL asset types with **multi-selection** support for both styles and asset types (batch generation). The lab covers 55+ regions organized in 13 parent groups. Narration scripts are **AI-generated via regional LLM routing** using `ai-universal-processor` with the zone-assigned provider (Claude for Western/EU/LATAM, Qwen for MENA/CJK, Gemini for India/SEA/Africa, GPT-4o for Pakistan/Caribbean/Eastern Europe). Each asset type has aligned messaging context (purpose, positioning, tone) that feeds the LLM prompt to ensure script-visual-TTS alignment. The lab visualizes the 5-stage AI pipeline and uses Supabase Edge Functions for secure generation.
